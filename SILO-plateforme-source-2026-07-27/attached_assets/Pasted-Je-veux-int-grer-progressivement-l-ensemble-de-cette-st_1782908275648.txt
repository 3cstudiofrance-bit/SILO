Je veux intégrer progressivement l’ensemble de cette stack dans la plateforme 3C Studio.

Important :
- Ne supprime rien de l’existant.
- Ne casse aucune page actuelle.
- Garde Supabase déjà configuré manuellement via les variables d’environnement.
- Travaille par modules.
- Si une clé API manque, crée la structure, les composants, les fichiers `.env.example` et utilise des mocks propres.
